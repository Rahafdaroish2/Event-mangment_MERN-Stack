## 💡 Key Concepts

### Components
The app is built with 8 main components, each handling a specific section:
- **Presentational Components:** Display data
- **Container Components:** Manage state
- **Route Components:** Handle navigation

### State Management
- Local component state with `useState`
- Session data with localStorage
- Parent-to-child props for data passing

### Routing
- `BrowserRouter` for app-wide routing
- `Routes` for path mapping
- `Link` and `navigate` for navigation

### Animations
- Framer Motion for smooth animations
- Variants for complex sequences
- Gesture animations for interactivity
